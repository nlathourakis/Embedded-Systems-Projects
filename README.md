# Arduino Learning Journey

A step-by-step series of Arduino projects, from blinking LEDs to a
self-balancing robot, built while learning embedded systems alongside
my Electrical & Computer Engineering studies at NTUA.

## Goal
Each project introduces one or two new components or concepts. The series
leads to a self-balancing robot (later on an STM32 with a custom KiCad PCB),
and includes an energy-focused project: a solar tracker with power measurement.
